# ATELIER — Modern Wardrobe

Landing page de demostración para una tienda de moda contemporánea. Proyecto conceptual para portafolio; no representa una marca comercial real.

## Tecnologías
- HTML5 semántico
- CSS3 responsive (desktop, tablet y móvil)
- JavaScript vanilla
- Google Fonts y fotografías remotas de Unsplash

## Funcionalidades de demostración
- Catálogo de seis productos con categorías
- Filtros por Mujer, Hombre y Accesorios
- Búsqueda simple de productos
- Añadir/quitar productos del carrito y cálculo de subtotal
- Favoritos
- Formulario de newsletter con respuesta demostrativa
- Menú móvil y panel lateral de carrito

## Ejecutar localmente
Abre `index.html` en un navegador. No requiere instalación ni proceso de compilación.

## Publicar en Netlify
1. Sube estos archivos a un repositorio GitHub.
2. En Netlify, selecciona **Add new site → Import an existing project**.
3. Conecta GitHub y selecciona el repositorio.
4. Build command: dejar vacío.
5. Publish directory: `.`.
6. Pulsa **Deploy site**.

## Importante
Todos los nombres, productos, precios y mensajes son ilustrativos. El carrito y el formulario son únicamente de demostración: no guardan pedidos, inventario ni suscripciones y no procesan pagos. Las fotografías se cargan desde URLs externas. La implementación final en WordPress/WooCommerce requerirá adaptar el diseño al CMS, confirmar catálogo y políticas comerciales, y configurar pagos, envíos e inventario según el alcance acordado.
